# Обучение ПостПромпт

Это официальные материалы мастерской «ПостПромпт» для работы в Codex.

Здесь находятся:

- техническая подготовка;
- конспекты микроуроков;
- материалы практик;
- инструкции, которые понадобятся по ходу обучения.

## Как использовать материалы

- Откройте эту папку как отдельный проект «Обучение ПостПромпт».
- Изучайте конспекты вместе с Codex и задавайте вопросы по непонятным местам.
- Используйте материалы для повторения действий из уроков и практик.
- Обновляйте официальные материалы только по явной команде.

## Команда для получения материалов

Создайте пустую папку, откройте её как отдельный проект в Codex и передайте
эту команду целиком:

```text
Получи официальные материалы курса по ссылке:

https://github.com/dezvin/PostPrompt

Загрузи материалы прямо в текущую папку проекта, без создания вложенной папки
PostPrompt.

Не создавай дополнительные служебные и учебные файлы.

После загрузки проверь результат и сообщи:

- какие папки и файлы появились;
- создалась ли вложенная папка PostPrompt;
- возникли ли ошибки.
```

## Команда для проверки новых уроков

Откройте проект «Обучение ПостПромпт» и передайте эту команду целиком:

```text
Проверь, появились ли новые уроки в официальных материалах курса:

https://github.com/dezvin/PostPrompt

Сравни материалы по ссылке с тем, что уже находится в текущем проекте.

Если появились новые уроки, загрузи их прямо в текущую папку, сохранив
существующую структуру.

Не создавай вложенную папку PostPrompt и дополнительные служебные или учебные
файлы.

Если новых уроков нет, ничего не изменяй и сообщи об этом.

После проверки сообщи:

- появились ли новые уроки;
- какие папки и файлы были добавлены;
- возникли ли ошибки.
```

## Граница учебного проекта

Этот проект предназначен только для обучения. Реальная работа, клиентские
материалы и собственный рабочий проект должны находиться в другой, полностью
отдельной папке и в другом проекте Codex.

Официальные материалы курса не нужно редактировать. Собственные заметки,
клиентские материалы и рабочие файлы храните вне этой папки.

## Порядок материалов

Папки пронумерованы в порядке прохождения:

1. `00_Техническая подготовка` — доступ, аккаунт, тариф и установка приложения.
2. `01_Знакомство с Codex и первый рабочий цикл` — первые микроуроки и практика.
3. `02_Учебная работа и управление Codex` — работа с учебным проектом и управление ходом работы агента.
4. `03_Контекст, инструкции и навыки Codex` — контекст проекта, инструкции, `AGENTS.md` и навыки.
5. `04_Выбор собственного проекта` — инструмент выбора проекта и материалы четвёртой практики.
6. `05_Создание собственного рабочего проекта` — урок и пятая практика о переходе от утверждённой карточки к отдельной рабочей среде в Codex.
7. `06_Установка и использование навыков` — работа с официальной документацией OpenAI, установка сторонних навыков и первая связка навыков курса.

Новые разделы будут добавляться по мере прохождения программы.
