# Доступы, разрешения и безопасные границы

## Зачем существуют разрешения

- Codex работает с компьютером и может выполнять реальные действия
- Обычная работа происходит внутри папки проекта
- Для некоторых действий Codex запрашивает дополнительное разрешение
- Запрос разрешения — это остановка перед выходом за установленную границу

## Что Codex может делать внутри проекта

- Читать файлы
- Создавать и редактировать материалы
- Выполнять обычные действия, необходимые для работы
- Не спрашивать подтверждение перед каждым безопасным действием
- Рабочая папка проекта остаётся основной границей

## Когда может появиться запрос

- Нужен файл за пределами проекта
- Требуется доступ к интернету
- Нужно выполнить действие вне обычной рабочей границы
- Затрагивается внешний сервис или другая часть компьютера
- Точное поведение зависит от выбранного режима разрешений

## Как читать запрос разрешения

- Что именно Codex собирается сделать
- Зачем это требуется для текущей задачи
- Какие файлы, папки или сервисы будут затронуты
- На какое время выдаётся разрешение
  - один раз
  - на текущую работу
  - постоянно
- Соответствует ли действие первоначальной задаче

## Как принимать решение

- Понятное и необходимое действие
  - разрешить в минимальном достаточном объёме
- Неожиданное или непонятное действие
  - не разрешать сразу
  - попросить Codex объяснить необходимость
- Слишком широкий доступ
  - отклонить
  - попросить более узкий способ выполнения
- Отказ в разрешении не ломает работу
  - Codex может предложить другой путь

## Режим разрешений

- Для обычной работы оставить безопасный режим по умолчанию
- Codex действует внутри проекта и спрашивает при выходе за его границы
- Не включать полный доступ только ради удобства
- Полный доступ убирает основные ограничения и не нужен для обычного обучения

## Главное правило

- Не нажимать разрешение автоматически
- Понимать действие до подтверждения
- Давать только тот доступ, который нужен прямо сейчас
- Если смысл запроса непонятен — остановиться и спросить Codex

## Что показать

- Где находится управление разрешениями
- Безопасный режим по умолчанию
- Пример запроса дополнительного доступа
- Как прочитать, что именно запрашивается
- Разрешение одного понятного действия
- Отклонение слишком широкого или непонятного запроса
