# Практика 2. Учебный проект как рабочая среда

## Проект «Обучение ПостПромпт»

- Единое место для материалов курса
- Продолжение обучения через работу с файлами
- Codex как помощник в изучении программы

## Получение материалов

- Открыть или создать учебный проект
- Загрузить материалы курса
- Проверить, какие файлы появились
- Получить новые материалы, если проект уже существует

## Ориентация в обучении

- Узнать, какие темы уже пройдены
- Понять, что изучать дальше
- Найти нужный конспект
- Получить объяснение непонятного места
- Разобраться, как пользоваться изученной возможностью

## Работа с материалами через Codex

- Читать материалы проекта
- Находить нужную информацию
- Сопоставлять сведения из нескольких файлов
- Объяснять содержание простыми словами
- Предлагать следующее действие на основе материалов

## Запрос как рабочая задача

- Описать задачу обычными словами
- Указать, какие материалы нужно использовать
- При необходимости наговорить мысли без готовой структуры
- Не расписывать за Codex каждое действие

## Контроль работы

- Понимать, что Codex собирается делать
- Отделять изучение материалов от изменения файлов
- Уточнять направление по ходу работы
- Осознанно выдавать необходимые разрешения
- Проверять результат в реальных файлах

## От материалов к полезному результату

- Понять содержание проекта
- Найти и собрать нужную информацию
- Определить возможное действие
- Поручить Codex выполнить работу
- Проверить, что получилось на самом деле
