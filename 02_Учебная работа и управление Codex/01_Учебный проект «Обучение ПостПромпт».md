# Учебный проект «Обучение ПостПромпт»

## Зачем нужен отдельный учебный проект

- Обучение — продолжительная работа, а не набор отдельных видео
- Все конспекты и материалы курса находятся в одном месте
- Здесь можно разбирать материалы вместе с Codex
  - задавать вопросы
  - просить объяснить непонятное
  - повторять действия из уроков
- Учебные материалы не смешиваются с реальной работой участника

## Создание проекта

- Создать пустую папку `Обучение ПостПромпт`
- Открыть её в Codex как отдельный проект
- Не создавать внутри дополнительные папки и служебные файлы вручную
- Пустой проект — нормальная отправная точка

## Получение материалов курса

- Официальный источник — открытая страница `PostPrompt`
- Участнику не нужно изучать GitHub и вводить технические команды
- Вставить в Codex готовую команду из описания к видео
- Codex самостоятельно загружает материалы в текущую папку
- Внутри появляются
  - техническая подготовка
  - конспекты микроуроков
  - материалы практик
  - `README.md` с объяснением структуры

## Работа с материалами курса

- Учебный проект помогает ориентироваться в программе и возвращаться к
  пройденному
- У Codex можно спросить
  - что уже было пройдено
  - что стоит сделать дальше
  - как пользоваться конкретной возможностью или выполнить нужное действие
- Codex находит подходящие материалы курса и помогает разобраться в них
- Проект становится не хранилищем конспектов, а постоянной средой обучения

## Учебный и рабочий проекты

- `Обучение ПостПромпт`
  - материалы курса
  - вопросы по урокам
  - повторение и освоение Codex
- Собственный рабочий проект
  - реальные задачи
  - собственные файлы
  - результаты работы
- Это два полностью отдельных проекта
- Рабочий проект не создаётся внутри учебного
- Из учебного проекта в рабочий переносится освоенный способ работы, а не папки
  и файлы
