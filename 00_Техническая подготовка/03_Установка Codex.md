# Видео 3. Установка Codex

## Что устанавливаем

- настольное приложение ChatGPT;
- внутри приложения находится Codex;
- приложение доступно для Windows и macOS;
- устанавливаем только с официальной страницы OpenAI.

## Скачивание

- убедиться, что сервисы OpenAI доступны в вашей стране и сети;
- соблюдать местное законодательство и правила используемых сервисов;
- открыть страницу загрузки;
- выбрать свою операционную систему;
- Windows;
- macOS;
- скачать установочный файл.

## Установка на Windows

- запустить установку;
- подтвердить установку приложения;
- дождаться завершения;
- найти ChatGPT в меню «Пуск»;
- открыть приложение.

## Установка на macOS

- открыть скачанный установочный файл;
- перенести ChatGPT в папку «Программы»;
- открыть приложение;
- подтвердить запуск, если macOS запросит разрешение.

## Вход в аккаунт

- выбрать вход через ChatGPT;
- для входа откроется браузер;
- если в браузере уже открыт нужный аккаунт ChatGPT, вход в приложение
  произойдёт через него;
- использовать тот же аккаунт, который был настроен ранее;
- использовать тот же способ входа;
- Google;
- почта и пароль;
- пройти подтверждение входа, если оно появится;
- убедиться, что открыт нужный аккаунт.

## Открыть Codex

- найти переключатель режимов;
- выбрать Codex;
- дождаться загрузки рабочего пространства;
- проверить, что открывается новый диалог Codex.

## Проверка приложения

- ChatGPT запускается с рабочего стола;
- вход выполнен в нужный аккаунт;
- внутри приложения доступен Codex;
- режим Codex открывается;
- отображается имя или почта нужного аккаунта;
- после перезапуска приложения вход сохраняется.

## Если приложение не открывается

- полностью закрыть и снова открыть приложение;
- перезагрузить компьютер;
- проверить наличие обновлений;
- повторно скачать приложение с официальной страницы;
- проверить, что используется поддерживаемая версия Windows или macOS;
- если проблема не решилась, написать в учебный чат.
