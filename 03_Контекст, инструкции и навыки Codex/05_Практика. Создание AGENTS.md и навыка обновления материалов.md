# Практика 3. Создание `AGENTS.md` и навыка обновления материалов

## Что было создано

- Проектный файл инструкций `AGENTS.md`
- Карта материалов `Карта проекта.md`
- Файл состояния обучения `Статус обучения.md`
- Правила оформления заметок `Формат личных заметок.md`
- Проектный навык обновления материалов курса
- Проверочный сценарий для правил проекта и навыка

## Извлечение правил из рабочего диалога

- Анализ истории разговора с Codex
- Отделение постоянных правил от ситуативных договорённостей
- Сбор требований перед созданием файлов
- Показ черновика правил в чате до записи на диск

### Базовое правило изменения файлов

- Codex не меняет файлы без разрешения
- Сначала показывает предлагаемые изменения в чате
- После утверждения записывает согласованный вариант

### Исключения

- `Статус обучения.md` обновляется автоматически после подтверждения, что очередная смысловая единица понятна
- `Карта проекта.md` обновляется автоматически после уже разрешённого создания, удаления, перемещения или переименования файла либо папки
- Автоматическое обновление карты не даёт Codex права самостоятельно менять структуру проекта
- Исключения нужны, чтобы состояние и навигация не отставали от реального проекта

## Разделение информации между файлами

### `AGENTS.md`

- Самые важные правила поведения Codex
- Границы самостоятельных действий
- Навигация к служебным файлам проекта
- Указание, какой файл и в какой ситуации нужно читать
- Без подробного дублирования всей структуры проекта

### `Карта проекта.md`

- Навигатор по урокам и другим материалам
- Одна строка на файл
- Краткое объяснение назначения каждого материала
- Первый источник для поиска нужного урока

### `Статус обучения.md`

- Пройденные смысловые единицы
- Текущая точка обучения
- Ближайшее продолжение
- Возможность восстановить состояние в новом диалоге

### `Формат личных заметок.md`

- Единый стандарт учебных заметок
- Последовательная нумерация: `01`, `02` и далее
- Отделение собственных заметок участника от официальных материалов курса

## Правило создания заметок

- Изначальная идея: создавать заметку после второго повторения одной мысли
- Проблема: после сжатия контекста Codex может не помнить первое появление мысли
- Принятое решение: сразу предлагать заметку, если появилось новое полезное знание
- Условие: знания ещё нет в материалах курса и существующих личных заметках
- Сначала проверить `Карта проекта.md`, затем указанный в ней первоисточник
- Если карта не дала маршрута, выполнить ограниченный поиск по Markdown-файлам
- После предложения дождаться согласия пользователя на создание заметки
- Показать черновик и записать заметку только после отдельного одобрения текста

## Первый проектный навык

### Повторяющаяся задача

- Ручной запрос на проверку новых материалов курса использовался регулярно
- Длинный промпт заменён короткой фразой: **«обнови материалы курса»**
- Порядок обновления перенесён из диалога в отдельный навык

### Проектирование навыка

- Использован специализированный `$skill-creator`
- Изучены требования к устройству навыков
- Определён неизменный порядок основных действий
- Для решений, зависящих от состояния проекта, оставлена необходимая вариативность Codex

### Два способа получения материалов

- Основной сценарий: обновление через установленный Git
- Резервный сценарий: скачивание файлов без Git
- Навык должен работать в обоих окружениях
- Проверка, подключён ли учебный проект к GitHub, исключена как лишнее усложнение
- Навык обращается к указанному официальному репозиторию напрямую
- Если официальный источник недоступен, навык ничего не меняет и сообщает об ошибке

### Конфликты файлов

- Изменённые участником уроки не перезаписываются автоматически
- При конфликте Codex сообщает о найденном изменении
- `README.md` разрешено обновлять автоматически
- Остальные файлы проекта сохраняются без изменений
- Новые официальные материалы добавляются все, а не только уроки
- В отчёте новые уроки отделяются от материалов другого типа

### Размещение навыка

- Навык создан по пути `.agents/skills/update-course-materials/SKILL.md`
- Он относится только к проекту «Обучение ПостПромпт»
- Автоматический запуск связан с просьбой проверить или обновить материалы курса
- Явный запуск остаётся доступен через символ `$`

### Проверка созданного навыка

- Штатный валидатор не запустился из-за отсутствия библиотеки YAML в доступных средах Python
- Дополнительные пакеты во время практики не устанавливались
- Структура, метаданные и содержимое `SKILL.md` проверены вручную
- `git diff --check` не обнаружил ошибок
