# Связывание глобальных навыков Codex и Antigravity

Готовый промпт к практике 9. Создаёт связь между папками навыков, чтобы не
поддерживать две отдельные копии. Вставляется в чат Antigravity.

## Перед использованием

- В промпте указаны пути из демонстрации на практике. Сначала попросите агента
  проверить реальные пути в вашей установке. В актуальной документации Codex
  глобальные пользовательские навыки размещаются в `~/.agents/skills`, поэтому
  `~/.codex/skills` нельзя считать универсальным путём. Если пути отличаются,
  сначала попросите адаптировать промпт к вашей конфигурации.
- Если в целевой папке уже есть собственные навыки, до выполнения промпта
  попросите агента сохранить их резервную копию и проверить совпадения имён с
  навыками Codex. Не разрешайте перезапись совпадающих файлов или удаление папки,
  пока не согласован перенос и не проверена сохранность всех её материалов.

Источники для проверки путей:
[навыки Codex](https://learn.chatgpt.com/docs/build-skills),
[навыки Antigravity](https://antigravity.google/docs/skills).

## Промпт

```markdown
Настрой синхронизацию скиллов между Codex и Antigravity через символическую связь (Junction/Symlink).

Выполни строго по шагам:

1. ОПРЕДЕЛИ ОС (Windows или macOS/Linux).

2. ПОДГОТОВЬ ИСТОЧНИК:
   - Проверь наличие папки ~/.codex/skills. Если её нет, создай её.

3. ПОДГОТОВЬ ЦЕЛЕВУЮ ПАПКУ:
   - Убедись, что родительская папка ~/.gemini/config существует (если нет — создай).
   - Проверь ~/.gemini/config/skills:
     * Если это уже рабочая ссылка/Junction на ~/.codex/skills — ничего не трогай.
     * Если это обычная папка с файлами — перенеси файлы в ~/.codex/skills и удали папку ~/.gemini/config/skills.
     * Если это пустая папка — удали её, чтобы освободить место для связи.

4. СОЗДАЙ СВЯЗЬ:
   - На Windows (в PowerShell):
     New-Item -ItemType Directory -Force -Path "$HOME\.gemini\config"
     New-Item -ItemType Junction -Path "$HOME\.gemini\config\skills" -Target "$HOME\.codex\skills"
   - На macOS / Linux (в Bash):
     mkdir -p ~/.gemini/config && ln -s ~/.codex/skills ~/.gemini/config/skills

5. ПРОВЕРКА:
   - Проверь чтение папки ~/.gemini/config/skills и выведи итоговый список подключённых скиллов.
```
