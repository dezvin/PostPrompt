# Микроурок 16. Выход из локального тупика через `zoom-out`

## Туннельное мышление агента

- Агент сосредоточился на одной детали
- Поставленная задача решается
  - цель проекта теряется
- Ответы становятся подробнее
  - движение не появляется
- Локальная задача могла оказаться
  - преждевременной
  - слишком узкой
  - только одним предполагаемым способом решения
- Признак
  - `Ответ правильный, но мы вообще не туда идём`

## Смена масштаба

- Команда
  - `$zoom-out`
- Остановка текущего пути
- Возврат к общей картине
  - цель проекта
  - нужный результат
  - пользователь результата
  - важные ограничения
  - дальнейшее использование
- Главный вопрос
  - `Какую задачу мы на самом деле пытаемся решить?`
- Новый взгляд
  - что является проблемой
  - что является только выбранным способом
  - что сейчас действительно мешает двигаться
- Возврат к работе
  - через более точную постановку задачи

## Пример: интеграция раньше пользы

- Проект
  - помощник для учёта личных расходов
- Локальный тупик
  - как автоматически получать данные из банков
- Агент обсуждает
  - сервисы
  - подключения
  - ограничения
  - стоимость
- Потерянная цель
  - помочь человеку увидеть расходы и финансовые риски
- После `zoom-out`
  - первая версия на одной готовой выписке
  - ручная загрузка данных
  - понятный отчёт
- Интеграция
  - отложена до проверки пользы
- Изменилось
  - не назначение проекта
  - способ и порядок работы

## Возвращение к работе

- Запуск навыка
  - `$zoom-out`
  - краткое описание возникшего тупика
- В ответе
  - что было потеряно
  - какая задача является главной
  - что сейчас можно не делать
  - какое действие имеет смысл следующим
- Если новая задача понятна
  - продолжить работу
- Если направление найдено, но маршрут ещё неизвестен
  - использовать `$nearest-clarity`
- Граница
  - не пересобирать весь проект
  - расширить взгляд настолько, чтобы снова увидеть правильное направление
