# Микроурок 15. Ближайший понятный участок через `nearest-clarity`

## Полный маршрут пока неизвестен

- Цель проекта уже понятна
- Первая полезная версия определена
- Но дальнейшая работа зависит от того
  - какие материалы действительно доступны
  - какие ограничения обнаружатся
  - что покажут первые результаты
- Две ошибки
  - придумать подробный план без достаточных оснований
  - выбрать одно действие и потерять общую цель
- Нужен маршрут
  - точный рядом
  - предварительный дальше

## Ближайший участок работы

- `$nearest-clarity`
  - сохраняет общий ориентир
  - выделяет часть работы, которую уже можно спланировать
- Ближайший участок
  - не одно действие
  - имеет понятное назначение
  - заканчивается самостоятельным результатом
- Внутри участка
  - что нужно сделать
  - что пока не трогать
  - какое действие будет первым
- Дальнейшие участки
  - показывают возможное направление
  - не становятся обещанным планом

## Пример: сначала проверить материалы

- Цель
  - создать первую полезную версию проекта
- Пока неизвестно
  - достаточно ли исходных материалов
  - доступны ли необходимые данные
  - какой способ реализации подойдёт
- Ближайший участок
  - проверить материалы и важные зависимости
- Работа внутри участка
  - собрать фактический список материалов
  - увидеть пробелы
  - определить критические ограничения
  - выбрать один обоснованный способ начать
- Результат участка
  - понятно, с чем можно работать
  - известно, чего не хватает
  - выбран следующий рабочий путь
- Первое действие
  - составить список имеющихся материалов и доступов

## Переход к следующему участку

- Запуск
  - `$nearest-clarity`
  - краткое описание цели и текущей неопределённости
- В ответе
  - общий ориентир
  - ближайший участок
  - результат его завершения
  - первое действие
  - предварительное продолжение
- После выполнения участка
  - посмотреть, что стало известно
  - изменить только затронутую часть маршрута
  - определить следующий понятный участок
- Если работа должна сохраниться между диалогами
  - зафиксировать её через `$manage-project-tasks`
