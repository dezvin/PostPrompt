# Микроурок 13. Установка сторонних навыков в Codex

## Готовый навык вместо создания с нуля

- В предыдущих уроках
  - разобрали устройство навыка
  - создали свой навык обновления материалов
- Повторяющаяся работа уже может быть упакована другим автором
- Готовый навык можно установить
  - не копировать инструкцию вручную
  - не собирать тот же способ работы с нуля
- Сначала
  - понятная задача
- Затем
  - подходящий навык

## Три способа работы с найденным навыком

- Использовать как есть
  - навык подходит под задачу
  - его правила и результат устраивают
- Адаптировать под себя
  - сохранить полезную основу
  - изменить неподходящие правила
  - убрать лишнее
  - добавить важные для своей работы ограничения
- Использовать как донора
  - изучить устройство навыка
  - найти полезные решения и рабочие механики
  - использовать их при создании собственного навыка
- Сначала проверить навык на реальной задаче
  - после этого решать, использовать его как есть, адаптировать или взять за основу

## Системный `$skill-installer`

- Уже входит в Codex
- Устанавливает навыки
  - из подборки OpenAI
  - из репозиториев GitHub
- Пользовательская установка
  - навык доступен в разных проектах
- После установки
  - навык появляется со следующего сообщения
- Запуск
  - `$skill-installer`

## Первая связка навыков курса

- Публичный репозиторий
  - `https://github.com/dezvin/codex-skills`
- Четыре навыка
  - `manage-project-tasks`
  - `nearest-clarity`
  - `zoom-out`
  - `zero-trust`
- Демонстрация
  - передать установщику репозиторий
  - указать четыре папки навыков
  - установить их как пользовательские
- Назначение навыков
  - не разбирать во время установки
  - каждому посвятить отдельный микроурок

## Проверка результата

- Сообщение установщика
  - какие навыки добавлены
  - куда они сохранены
- Следующее сообщение
  - начать вводить `$`
  - найти четыре установленных навыка
- Появление навыка в списке
  - можно переходить к его использованию

## Другие источники навыков

- Встроенная подборка OpenAI
  - посмотреть доступные варианты через `$skill-installer`
- Публичные каталоги
  - пример: `https://skills.sh/`
- Каталог
  - помогает найти навык
  - ведёт к исходному репозиторию
- Перед установкой
  - понять назначение
  - найти исходные файлы
  - посмотреть содержимое пакета
  - проверить необходимые доступы
- Общий маршрут
  - найти
  - изучить
  - установить
  - проверить появление
- Не устанавливать всё подряд
  - навык подключается под реальную задачу
