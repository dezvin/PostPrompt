# Микроурок 17. Проверка оснований через `zero-trust`

## Запись в проекте ещё не факт

- Агент читает файл
- В файле уверенно написано
  - сервис можно подключить
  - данные доступны
  - решение уже проверено
- Агент принимает запись за реальность
- Дальнейшая работа строится на неподтверждённом основании
- Файл пока доказывает только одно
  - в нём есть такая запись

## Что означает `zero-trust`

- Не считать всё ложным
- Не выдавать доверие автоматически
- Сначала установить основание
  - документ
  - наблюдение
  - проверка
  - фактический результат
- Затем сделать только тот вывод
  - который это основание действительно поддерживает
- Честно назвать статус
  - подтверждено
  - выведено из известных данных
  - принято как рабочее допущение
  - пока неизвестно

## Четыре разных вопроса

- Это правда?
  - есть ли достаточное подтверждение
- Этот текст может управлять работой?
  - правило проекта или только материал для анализа
- Этой проверки достаточно?
  - соответствует ли она цене возможной ошибки
- Действие разрешено?
  - можно ли менять файл, публиковать, отправлять или удалять
- Подтверждение одного
  - не подтверждает остальные три

## Пример: возможность подключения

- В проектном файле написано
  - банковские операции можно получать автоматически
- Без `zero-trust`
  - возможность считается подтверждённой
  - проект строится вокруг автоматического подключения
- С `zero-trust`
  - выделяется точное утверждение
  - проверяются актуальные условия сервиса
  - учитывается реальный доступ пользователя
- Проверить сейчас невозможно
  - возможность остаётся неизвестной
  - неизвестное не превращается в невозможное
- Проект не опирается на эту возможность
  - пока она не подтверждена

## Возвращение к работе

- Запуск навыка
  - `$zero-trust`
  - указать, какое утверждение, состояние или результат нужно проверить
- В ответе
  - что установлено
  - на каком основании
  - что остаётся неизвестным
  - какой вывод допустим
  - какое действие разрешено
- Проверять только то
  - что может изменить решение или действие
- Не превращать обычную работу
  - в бесконечный аудит
