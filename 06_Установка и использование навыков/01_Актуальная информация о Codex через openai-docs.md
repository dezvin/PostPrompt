# Микроурок 12. Актуальная информация о Codex через `openai-docs`

## Ответ модели может устареть

- Codex может отвечать из знаний модели
- Продукты OpenAI продолжают меняться
  - появляются новые возможности
  - меняются модели и настройки
  - обновляются рекомендации
- Для текущего ответа нужна проверка
  - не вспоминать, как было раньше
  - обратиться к официальной документации

## Что делает `openai-docs`

- Системный навык Codex
  - уже доступен
  - не требует установки
- Работает с официальной документацией OpenAI
- Получает вопрос пользователя
- Находит вероятное место с ответом
  - поиск по конкретной теме
  - карта документации для широкого вопроса
- Открывает подходящие страницы
- Проверяет, что в них действительно написано
- Возвращает
  - понятный ответ
  - ссылки на источники
  - честную границу, если точного ответа нет

## Когда навык может помочь

- Разобраться в возможностях Codex
  - навыки
  - цели
  - автоматизации
  - настройки
  - работа с файлами и инструментами
- Научиться лучше ставить задачи модели
- Понять контекст
  - размер контекстного окна
  - сжатие
  - возможность изменить лимит
- Выбрать модель
  - какие модели доступны
  - чем отличаются
  - какая подходит для конкретной работы
- Разобраться с ошибкой или непонятным поведением
- Проверить старый совет или инструкцию
- Исследовать новую задачу
  - может ли Codex её выполнить
  - какие возможности могут помочь
  - что уже поддерживается
  - что придётся дополнительно настроить или создать
- Список не ограничен этими примерами
  - подходит любой вопрос о Codex и продуктах OpenAI, для которого важна актуальная официальная информация

## Как поставить задачу

- Явно вызвать `$openai-docs`
- Описать, что хочется понять или сделать
- Попросить проверить актуальную документацию
- Указать удобный результат
  - короткое объяснение
  - сравнение
  - инструкция
  - варианты реализации
- Попросить дать ссылки на источники

### Примеры запросов

- `Используй $openai-docs и объясни по официальной документации OpenAI, что такое цели в Codex и для каких задач они нужны.`
- `Используй $openai-docs и проверь, какие модели сейчас доступны в Codex, чем они отличаются и какая лучше подходит для моей задачи.`
- `Я хочу реализовать в Codex следующую задачу: [описание]. Используй $openai-docs и найди в официальной документации возможности, которые могут мне помочь.`

## Демонстрация работы

- Выбрать один реальный вопрос о Codex
- Запустить `$openai-docs`
- Посмотреть ход работы
  - поиск подходящего раздела
  - открытие страницы
  - проверка содержания
- Получить ответ
  - основной вывод
  - найденные возможности
  - ссылки на документацию
- Открыть одну ссылку
  - увидеть основание ответа
  - отличить подтверждённое от предположения
