# Микроурок 14. Задачи, которые не теряются между диалогами

## Чат не заменяет список задач

- Работа над проектом продолжается
  - диалог заканчивается
  - незавершённая задача остаётся
- Если задача обсуждалась только в чате
  - новый диалог может о ней не знать
  - агент не видит, где остановилась работа
- Долговременная задача
  - должна пережить текущий диалог
  - сохраняется в файлах проекта
- Не нужно сохранять
  - обычное обсуждение
  - идею без решения работать над ней
  - действие, которое уже выполнено

## `manage-project-tasks` в рабочем проекте

- Навык ведёт долговременные задачи
- Открытая работа
  - `TODO.md`
- Завершённая и отменённая работа
  - `archive/tasks/YYYY-MM.md`
- В проектном `AGENTS.md`
  - короткое правило использовать `$manage-project-tasks`
  - фиксировать появившиеся задачи
  - обновлять их по ходу работы
  - завершать или отменять
  - переносить закрытые задачи в архив
- Подробный порядок
  - остаётся внутри навыка
  - не копируется в `AGENTS.md`

## Одна задача от появления до архива

- Во время работы появилась задача
  - собрать исходные материалы для первой версии проекта
- Задача не выполняется в текущем диалоге
  - записывается в `TODO.md`
- Работа началась
  - фиксируется текущее действие
  - указывается, откуда продолжать
- Появились новые сведения
  - задача обновляется
  - ненужные детали не сохраняются
- Материалы действительно собраны
  - результат проверен
  - задача переносится в месячный архив
  - из `TODO.md` удаляется
- Обещание выполнить работу
  - не означает, что задача завершена

## Продолжение в новом диалоге

- Новый диалог
  - читает `TODO.md`
  - видит незавершённую работу
  - понимает текущую точку
  - продолжает с ближайшего действия
- Пересказывать всю историю чатов не нужно
- Основание для продолжения
  - состояние, сохранённое в проекте
  - не память предыдущего диалога
- Закрытая задача
  - при необходимости находится в архиве
