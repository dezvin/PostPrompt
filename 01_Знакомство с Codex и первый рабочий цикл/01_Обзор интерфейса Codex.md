# Обзор интерфейса Codex

## ChatGPT и Codex в одном приложении

- Переключение между ChatGPT и Codex
  - ChatGPT
  - Codex
- Как понять, какой раздел сейчас открыт
- Возвращение из Codex в обычный ChatGPT
- `Quick chat`
  - быстрый обычный диалог ChatGPT
  - отличие от диалога Codex только на уровне расположения в интерфейсе

## Боковая панель

- `New chat`
  - создание нового диалога Codex
- Дополнительные разделы
  - плагины
  - навыки
- Проекты
  - общий список проектов
  - открытие выбранного проекта
  - закреплённые проекты
- Диалоги
  - диалоги внутри проекта
  - недавние диалоги
  - открытие существующего диалога
  - переименование, закрепление и архивирование
  - копирование идентификатора диалога
    - использование контекста одного диалога в другом
- Поиск по проектам и диалогам
- Сворачивание и разворачивание боковой панели

## Экран проекта

- Название открытого проекта
- Папки, подключённые к проекту
- Список диалогов проекта
- Создание нового диалога внутри проекта
- Переход между диалогами без выхода из проекта
- Меню проекта
  - изменение проекта
  - добавление папки
  - закрепление
  - архивирование диалогов

## Рабочая область диалога

- История разговора
  - сообщения человека
  - ответы Codex
- Контекст диалога
  - индикатор заполнения
  - автоматическое сжатие истории
- Боковой диалог
  - вопрос без перегрузки основного диалога
  - переход из выделенного фрагмента ответа
- Текущая работа Codex
  - состояние выполнения
  - отображение выполняемых действий
  - сообщения о найденных материалах
  - запрос дополнительной информации или подтверждения
- Дополнительная панель диалога
  - план работы
  - использованные источники
  - созданные файлы
  - краткая сводка диалога
- Возвращение из открытого материала к диалогу

## Поле запроса

- Основное поле для сообщения
- Прикрепление файлов и изображений
  - выбор файла с компьютера
  - отображение прикреплённого материала перед отправкой
  - удаление ошибочно прикреплённого файла
- Отправка сообщения
- Остановка выполняющейся работы
- Выбор модели
  - Sol
  - Terra
  - Luna
- Глубина рассуждения
- Влияние выбранных настроек на расход лимита
- Голосовой ввод
  - свободная надиктовка мыслей
- Индикаторы и переключатели рядом с полем
  - текущий режим доступа
  - дополнительные возможности диалога

## Как отображается работа Codex

- Начало выполнения задачи
- Этапы и действия внутри диалога
- Открытие подробностей отдельного действия
- Разница между состояниями
  - Codex работает
  - Codex ждёт решения человека
  - работа завершена
  - действие не удалось
- Возможность вернуться к более раннему сообщению или действию

## Созданные и найденные материалы

- Файлы, появившиеся в диалоге
  - название файла
  - расположение файла
  - открытие по ссылке или карточке
- Предварительный просмотр рядом с диалогом
  - документы
  - таблицы
  - презентации
  - PDF
  - изображения
  - веб-страницы
  - встроенный браузер
  - терминал
- Переключение между визуальным представлением и исходным содержимым, если оно доступно
- Закрытие предварительного просмотра и возвращение к разговору

## Просмотр изменений

- Где открывается панель изменений
- Список изменённых файлов
- Что было добавлено и удалено
- Переход к конкретному месту в файле
- Изменения за последний ответ Codex
- Панель может быть доступна не в каждом проекте

## Режим доступа и запросы подтверждения

- Где отображается текущий режим доступа
- Как выглядит запрос на подтверждение действия
- Что показывается перед решением
  - какое действие требуется
  - к чему Codex хочет получить доступ
- Кнопки подтверждения и отказа
- Возвращение к диалогу после принятого решения

## Настройки приложения

- Открытие `Settings`
  - через меню приложения
  - `Ctrl + ,` в Windows
- Основные разделы
  - общие настройки
  - сочетания клавиш
  - уведомления
  - внешний вид
  - персонализация
  - память
  - архивированные диалоги
- Профиль и аккаунт
  - оставшийся недельный лимит
  - дата обновления лимита
- Возвращение из настроек в Codex
