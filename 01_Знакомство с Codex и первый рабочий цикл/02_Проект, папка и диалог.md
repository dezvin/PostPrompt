# Проект, папка и диалог — разные вещи

## Три части одной рабочей среды

- Проект
  - объединяет продолжительную связанную работу
- Папка
  - хранит материалы и результаты на компьютере
- Диалог
  - хранит разговор с Codex по отдельному результату или этапу
- Проект, папка и диалог связаны, но не заменяют друг друга

## Проект

- Рабочее направление, к которому нужно возвращаться
- Общий контур для связанных материалов и задач
- Внутри одного проекта
  - одна или несколько подключённых папок
  - несколько отдельных диалогов
- Проект продолжается после завершения одного диалога
- Один проект не означает одну задачу
- Примеры проектов
  - разработка курса
  - работа с отдельным клиентом
  - запуск продукта
  - подготовка исследования
- Два параллельных проекта участника
  - учебный проект с конспектами и материалами курса
  - собственный рабочий проект

## Папка

- Обычное место на компьютере
- Внутри лежат реальные файлы
  - исходные материалы
  - черновики
  - готовые результаты
- Папка существует независимо от Codex
  - её можно открыть через Проводник
  - файлы остаются на компьютере после закрытия приложения
- Подключение папки к проекту
  - Codex получает доступ к находящимся в ней материалам
  - диалоги проекта могут работать с одними и теми же файлами
- Основная папка
  - место, с которого начинаются новые диалоги проекта
- Дополнительные папки
  - подключаются, когда связанная работа лежит в разных местах
- Папка проекта по умолчанию
  - создаётся в `Документы/ChatGPT`, если другое место не выбрано
- `PROJECT.md`
  - общая карта проекта
  - цели и текущее состояние
  - структура и ключевые материалы
  - помогает новому диалогу быстро восстановить контекст

## Диалог

- Отдельный разговор внутри проекта
- Собственная история сообщений
- Отдельный результат или этап общей работы
- Диалог использует материалы подключённых папок
- Новый диалог
  - не удаляет проект
  - не создаёт новую копию папки
  - не переносит автоматически всю историю другого диалога
  - может продолжить общую работу по тем же файлам
- Один проект может содержать разные диалоги
  - разобрать исходные материалы
  - собрать структуру
  - подготовить отдельный текст
  - проверить готовый результат

## Один проект — несколько результатов

- Проект «Разработка курса»
  - общая работа, которая продолжается несколько недель
- Папка курса
  - программа
  - материалы занятий
  - задания
  - готовые файлы для участников
- Отдельные диалоги
  - анализ исходных материалов
  - разработка программы
  - подготовка первого урока
  - проверка задания
- Все диалоги относятся к одному проекту
- Каждый диалог решает свою часть работы
- Результаты остаются в общей папке

## Как они связаны

- Проект удерживает общую работу
- Папка удерживает реальные материалы
- Диалог удерживает ход отдельной задачи
- Несколько диалогов могут читать и изменять одни и те же файлы
- Закрытие диалога не закрывает проект
- Новый диалог не означает начало всей работы с нуля
- Файл важнее сообщения, если результат должен сохраниться и использоваться дальше

## Как не смешивать сущности

- «Мне нужен новый результат»
  - отдельный диалог внутри существующего проекта
- «Начинается другое рабочее направление»
  - отдельный проект
- «Нужно дать Codex ещё материалы»
  - добавить файлы в подключённую папку или подключить другую папку
- «В одном диалоге накопилось несколько разных задач»
  - разделить их на отдельные диалоги
- «Закончен один этап»
  - проект может продолжаться в следующем диалоге
- «В папке накопился беспорядок»
  - попросить Codex изучить файлы и предложить новую структуру

## Что показать в приложении

- Открытый проект
  - название проекта
  - подключённая папка
- Несколько диалогов внутри проекта
  - разные названия
  - разные истории сообщений
- Один файл из общей папки
  - открывается через проект
  - остаётся на компьютере
  - действия с файлом
    - открыть во внешнем редакторе
    - скопировать путь или содержимое
    - показать в Проводнике
- Просмотр изменений файла
  - сравнение состояния до и после работы Codex
- Переход из одного диалога в другой
  - проект не меняется
  - подключённая папка не меняется
  - меняется история конкретного разговора
