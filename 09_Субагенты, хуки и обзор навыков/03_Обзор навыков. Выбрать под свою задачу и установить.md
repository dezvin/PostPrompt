# Микроурок 24. Обзор навыков: выбрать под свою задачу и установить

## Где взять навыки

- [Репозиторий навыков Олега: dezvin/codex-skills](https://github.com/dezvin/codex-skills)
  - в `README.md` находятся каталог, описания и команды установки
  - каждый навык хранится в отдельной папке
  - навыки можно устанавливать по одному
- Часть каталога уже знакома по курсу
  - управление задачами через `manage-project-tasks`
  - движение ближайшими понятными участками через `nearest-clarity`
  - выход из локального тупика через `zoom-out`
  - проверка оснований через `zero-trust`
  - выявление требований через `grill-me`
  - проектирование навыка через `skill-designer`
  - подготовка проекта реализации через `design-pass`
- В этом обзоре
  - другие навыки из согласованной подборки
  - какую работу им поручать
  - какой результат получать
  - как продолжить изучение каталога вместе с Codex

## Как выбрать навык

- Начать со своей задачи
  - что сейчас нужно сделать
  - какие материалы уже есть
  - какой результат поможет продолжить работу
- Сопоставить задачу с назначением навыка
  - название помогает найти кандидата
  - описание и `SKILL.md` объясняют, подходит ли он
- Учитывать условия использования
  - нужны ли дополнительные программы
  - требуется ли доступ к сервису
  - есть ли платные действия
  - доступны ли необходимые инструменты и помощники
- Выбирать под текущую работу
  - для переноса работы между чатами обратить внимание на `handoff`
  - для сокращения перегруженных материалов на `token-efficient`
  - остальные навыки выбирать по конкретной задаче исследования, анализа, визуала или сайта

## Продолжение работы и сохранение разговора

### Передать работу в другой чат: handoff

- [Навык handoff](https://github.com/dezvin/codex-skills/tree/main/skills/handoff)
- Собирает сведения, необходимые для продолжения выбранной работы
  - цель и текущий результат
  - принятые решения
  - ограничения
  - нужные файлы
  - ближайшее действие
- Готовит материал передачи и запрос для нового чата
  - следующему агенту проще начать с нужного рабочего состояния
  - посторонние темы из разговора в передачу не включаются
- Пример поручения
  - `Используй $handoff. Подготовь передачу работы над этим конспектом в новый чат. Сохрани принятые требования, текущую версию и оставшиеся вопросы.`

### Сохранить историю текущего чата: export-current-thread

- [Навык export-current-thread](https://github.com/dezvin/codex-skills/tree/main/skills/export-current-thread)
- Сохраняет читаемую стенограмму текущей ветки Codex в локальный `.txt`
  - разговор
  - отметки подтверждённого чтения файлов
- Полезен, когда нужна сама история работы
  - вернуться к обсуждению
  - найти прежнюю формулировку
  - восстановить ход разговора
- Запускается по явной просьбе
- Различие с `handoff`
  - `handoff` отбирает рабочие сведения для продолжения конкретной задачи
  - `export-current-thread` сохраняет разговор как историю

### Убрать лишний объём: token-efficient

- [Навык token-efficient](https://github.com/dezvin/codex-skills/tree/main/skills/token-efficient)
- Создаёт или сокращает материал до необходимого объёма
  - ответы и документы
  - задания агентам
  - инструкции и навыки
- Сохраняет то, что определяет смысл и использование
  - условия
  - ограничения
  - исключения
  - порядок действий
  - существенные различия
- Пример поручения
  - `Используй $token-efficient. Сократи эту инструкцию без потери требований, условий и понятности. Не задавай искусственный предел длины.`

## Исследование и работа с источниками

### Подготовить задание для исследования: research-prompter

- [Навык research-prompter](https://github.com/dezvin/codex-skills/tree/main/skills/research-prompter)
- Превращает исследовательский замысел в самостоятельное задание
  - что нужно выяснить
  - зачем нужен результат
  - какой контекст учитывать
  - какие вопросы и ограничения существенны
- Задание можно передать в Deep Research или Deep Search
- Помогает проверить предложенный исследователем план перед запуском
- Само исследование этот навык не проводит
  - его результатом становится готовое задание

### Провести исследование в Codex: adaptive-web-research

- [Навык adaptive-web-research](https://github.com/dezvin/codex-skills/tree/main/skills/adaptive-web-research)
- Подходит для вопроса с несколькими направлениями
  - сравнение подходов
  - поиск противоречий
  - выяснение причин
  - рекомендация с основаниями
- Организует поиск, чтение и сопоставление источников
  - исследовательские помощники получают материалы
  - аналитик разбирает найденное
  - основной агент собирает ответ
  - при обнаружении пробела поиск уточняется
- Для работы нужны доступный веб-поиск и предусмотренные помощники
  - пакет содержит их шаблоны
  - установка недостающих помощников согласуется отдельно
  - после первой настройки может понадобиться новый чат или перезапуск Codex
- Различие с `research-prompter`
  - один готовит задание для исследования
  - другой проводит исследование внутри Codex

### Узнать, как люди формулируют поиск: wordstat

- [Навык wordstat](https://github.com/dezvin/codex-skills/tree/main/skills/wordstat)
- Собирает поисковые формулировки вокруг темы
  - Yandex Wordstat
  - подсказки Яндекса, Google и YouTube
- Показывает направления и доступные частотности
  - может сравнивать несколько тем при одинаковых условиях сбора
  - сохраняет данные для последующей работы
- Помогает увидеть язык поисковых запросов
  - какие вопросы задают
  - какие соседние направления появляются
- Данные требуют дальнейшего осмысления
  - отсутствие измерения не означает нулевой спрос
  - частотность сама по себе не доказывает привлекательность бизнеса
- Для запуска нужны Python 3.11+ и настроенный доступ к используемым сервисам
  - отдельный добор частотностей через Topvisor является платным действием

### Разобраться в задачах аудитории: analyze-audience-jtbd

- [Навык analyze-audience-jtbd](https://github.com/dezvin/codex-skills/tree/main/skills/analyze-audience-jtbd)
- Помогает понять, какого изменения человек хочет добиться
  - какую задачу решает
  - что подталкивает его к решению
  - что мешает выбрать и начать
  - какие альтернативы он рассматривает
- Может создать анализ с нуля или выполнить отдельную часть
  - разобрать интервью и клиентские материалы
  - выделить различающиеся задачи аудитории
  - уточнить существующий анализ по новым сведениям
- Различает основания выводов
  - наблюдение из материалов клиента
  - исследовательские данные
  - гипотеза модели
- Полезен для решений о продукте, предложении и коммуникации

### Прочитать конкретный пост Telegram: telegram-post-reader

- [Навык telegram-post-reader](https://github.com/dezvin/codex-skills/tree/main/skills/telegram-post-reader)
- Получает текст и прикреплённые изображения по прямой ссылке на публичный пост
  - например, `https://t.me/имя_канала/123`
- Позволяет использовать пост как источник для текущей задачи
  - разобрать аргумент
  - сравнить с другим материалом
  - извлечь нужные сведения
- Границы
  - нужен конкретный публично доступный пост
  - навык не ищет по всей истории канала
  - не получает доступ к закрытым материалам
  - не расшифровывает аудио и видео
- При установке нужно проверить зависимости скрипта, указанные в пакете

## Визуальные задачи и работа с сайтом

### Подготовить запрос для изображения: universal-visual-prompt-builder

- [Навык universal-visual-prompt-builder](https://github.com/dezvin/codex-skills/tree/main/skills/universal-visual-prompt-builder)
- Превращает идею в готовый запрос для создания или изменения изображения
  - выбирает подходящее визуальное направление
  - учитывает формат, стиль и предоставленные примеры
  - помогает исправить слабый запрос или результат
- Результат навыка
  - текст запроса
- Само изображение создаётся отдельно
  - через доступный инструмент генерации или редактирования
- Пример поручения
  - `Используй $universal-visual-prompt-builder. Подготовь запрос для обложки этого материала. Учти тему и приложенные примеры. Сначала покажи текст запроса.`

### Обновить сайт на Beget: manage-beget-site

- [Навык manage-beget-site](https://github.com/dezvin/codex-skills/tree/main/skills/manage-beget-site)
- Организует работу с сайтом, размещённым на Beget
  - публикацию изменений
  - резервное копирование
  - восстановление
  - перенос и проверку результата
- Перед изменением выясняет фактическое устройство сайта
  - откуда берутся файлы и содержимое
  - что находится на работающем сайте
  - какие данные нужно сохранить
  - как проверить изменение и выполнить откат
- Для действий нужен соответствующий доступ
  - установка навыка сама по себе доступа не предоставляет
  - изменение работающего сайта требует явного разрешения

## Как установить выбранный навык

1. Открыть каталог и выбрать нужный навык
   - сверить назначение со своей задачей
   - взять команду из его раздела в `README.md`
2. Попросить системный `$skill-installer` установить выбранный пакет
   - пример для `handoff`
   - `Используй $skill-installer и установи глобально skill handoff из: https://github.com/dezvin/codex-skills/tree/main/skills/handoff. Если skill уже установлен, не перезаписывай его и сообщи об этом.`
3. Проверить дополнительные условия из описания пакета
   - программы и зависимости
   - доступы к сервисам
   - необходимые помощники
4. В следующем сообщении проверить доступность навыка и вызвать его
   - через `$` и название
   - вместе с конкретной задачей и материалами
   - если установленный навык не появился, перезапустить Codex; такой порядок описан в [документации OpenAI](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)

- Подробный порядок установки уже разобран в микроуроке 13
- Глобальная установка делает навык доступным в разных проектах
- Изменения репозитория не обновляют установленную копию автоматически
  - существующий пакет обновляется отдельно
  - перед обновлением нужно учитывать свои изменения

## Как изучать репозиторий вместе с Codex

- Можно описать свою работу обычными словами
  - чем занимаетесь
  - что сейчас хотите сделать
  - какие материалы и инструменты уже есть
- Попросить Codex прочитать актуальный каталог
  - выбрать подходящие навыки
  - изучить инструкции кандидатов
  - объяснить применение на вашей задаче
- Готовый запрос
  - `Изучи актуальный README репозитория https://github.com/dezvin/codex-skills. Моя работа и текущая задача: [описание]. Подбери подходящие навыки. Для кандидатов прочитай SKILL.md и необходимые связанные материалы. Объясни простыми словами, что каждый поможет сделать, какой результат вернёт и какие условия нужны. Покажи пример запроса на моей задаче и помоги выбрать, что установить первым. Пока ничего не устанавливай и не запускай.`
- После выбора
  - установить нужный навык
  - дать ему конкретное поручение
  - оценить результат на своей работе
  - возвращаться к каталогу при появлении другой задачи
