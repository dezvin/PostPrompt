# Микроурок 19. Выявление скрытых требований через `Grill Me`

## В первоначальной идее видны не все требования

- Человек описывает, что хочет создать
- Codex может начать проектировать решение
- Но часть важных решений ещё не сформулирована
  - что должно происходить обязательно
  - где проходит граница системы
  - что удобнее пользователю
  - какие последствия неприемлемы
- Если не обсудить эти решения
  - Codex заполнит пробелы своими предположениями
  - внешне связный проект может не соответствовать реальной задумке

## Прожарка решения через `Grill Me`

- `$grill-me`
  - ищет развилки, которые существенно меняют дальнейшую работу
  - задаёт по одному вопросу за раз
  - предлагает рекомендуемый вариант
- Следующий вопрос зависит от предыдущего ответа
- Уже принятые решения сохраняются
  - к ним не нужно возвращаться без новой причины
- Вопрос задаётся только тогда
  - когда решение действительно принадлежит пользователю
  - когда разные ответы изменят результат или границы работы
- Навык не перекладывает на пользователя то, что Codex может
  - установить по источникам
  - безопасно решить самостоятельно
  - проверить на практике

## Пример с метасистемой проектов

- Исходная идея
  - собрать задачи из нескольких проектов
  - помогать человеку управлять общей работой
- Первый очевидный вариант
  - каждое утро показывать все задачи
- Вопрос прожарки
  - человеку нужна полная картина или короткий рабочий фокус
- Подтверждённое решение
  - утренняя сводка показывает сроки, долги и фокус дня
  - полный обзор открывается отдельно по запросу
- Следующий вопрос
  - должна ли метасистема сама напоминать о задачах в нужное время
- Подтверждённая граница
  - Codex анализирует планы и фактическое выполнение
  - будильники и жёсткие напоминания остаются во внешнем приложении
- Несколько последовательных вопросов
  - превращают общую задумку в конкретные требования

## Как установить `Grill Me`

- Открыть проект `Обучение ПостПромпт`
- Попросить агента
  - получить новые материалы курса
  - найти конспект об установке сторонних навыков
  - определить по нему, как установить `Grill Me`
- Два варианта продолжения
  - агент по аналогии составляет готовый запрос для установки
  - пользователь передаёт агенту ссылку на репозиторий `codex-skills` и просит установить оттуда `Grill Me`
- После установки
  - убедиться, что навык доступен в Codex

## Как провести прожарку своего решения

- Открыть проект, решение которого нужно проверить
- Передать Codex
  - какое решение нужно прожарить
  - к какому следующему действию или этапу готовится проект
- Запустить
  - `$grill-me`
- Отвечать на один вопрос за раз
- Не просить заранее полный перечень вопросов
  - новые развилки проявляются из предыдущих ответов

## Что делать с результатом

- В конце отделить
  - подтверждённые решения
  - рабочие допущения
  - то, что нужно проверить
  - вопросы, которые остались открытыми
- Не оставлять результат только в истории диалога
- Передать Codex итог прожарки и попросить определить
  - какие сведения относятся к описанию проекта
  - какие решения нужно добавить в рабочие файлы
  - какие проверки или дальнейшие действия нужно сохранить
- Дальнейший этап зависит от предмета прожарки
  - уточнить описание или требования проекта
  - обновить рабочие данные
  - продолжить проектирование решения
  - подготовить план реализации
  - спроектировать собственный навык, если прожарка относилась именно к навыку
